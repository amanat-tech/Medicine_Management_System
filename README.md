**MEDICINE MANAGEMENT SYSTEM 💊**
This is a Medicine Management System built using C++ and File Handling. 
It allows you to manage pharmacy records efficiently without needing an external database.

******👉Project Features******
Here are the core modules of the project:
**Login & Register:**      Secure user authentication using file-based storage.
**Add Medicine:**           Insert new medicine records into the system.
**Search Medicine:**       Quickly find any medicine from the records.
**Update Medicine:**        Modify existing medicine stock levels.
**View Medicines:**        Display a complete list of all stored medicines.
**Delete Medicine:**        Remove specific medicine records permanently.
